COLLECTION PRODUCT IMAGES
=========================

Upload product photos here with the same filenames used in
assets/collection-products.js:

  01.jpg  → Everyday Comfort Bra
  02.jpg  → Soft Cotton Panty Pack
  ...
  20.jpg  → Padded Push-Up Bra
  21.jpg  → (your next product)

Recommended size: 800 × 1000 px (portrait 4:5)
Format: JPG or WebP

Until images are uploaded, the page uses fallback photos
from assets/images/products/ and assets/images/showcase/.

To add product #21:
1. Save image as 21.jpg in this folder
2. Edit assets/collection-products.js — add new entry to products array
